# 日本株監視アシスタント

気になる日本企業を登録しておくと、毎朝自動で株価・財務指標が更新され、
iPhoneのSafari（ホーム画面に追加可能）から短時間で変化を確認できる
個人用の株式監視Webアプリです。

収益化・常駐サーバーは一切なく、維持費はゼロです（GitHub の無料枠のみで動作します）。

## できること（現時点）

- 監視銘柄の登録・削除・一覧表示（銘柄コード・企業名・株価・前日比・PER・PBR・ROE・
  売上高成長率・営業利益成長率・配当利回り・データ更新日時）
- 購入検討価格・投資理由メモ・監視条件（価格しきい値、変動率、PER/PBR条件、決算更新通知、
  売上高/営業利益の大幅変化通知）の登録
- 条件に該当した銘柄を画面上でハイライト表示
- 明示的なルールに基づく「割安成長株」抽出（AIは判定に一切関与しません。PEG・成長率・
  自己資本比率・営業利益率・52週高値からの下落率などの数値のみで判定）
- iPhone Safari 対応・PWA（ホーム画面に追加可能）
- データが取得できない項目は「取得不可」と表示（推測値を表示しません）

## 画面構成

- **一覧**: 登録銘柄のカード表示。株価・指標・アラート・メモを確認
- **登録・管理**: 銘柄コード/企業名で検索して登録。購入検討価格・メモ・監視条件を設定
- **抽出**: 取得済みデータの中から、ルールベースで割安成長株をランキング表示
- **設定**: データ取得元の情報、バックアップ（JSON書き出し/読み込み）

## アーキテクチャと設計方針

```
J-Quants API (J-Quants社)
  → GitHub Actions（平日朝、自動実行）
  → Python が株価・財務データを取得し data/watchlist.db（SQLite）に保存
  → site/data/*.json を生成（公開情報のみ。個人データは含まない）
  → GitHub Pages で配信
  → iPhone Safari（PWA）が fetch() で JSON を読み込み、
    ブラウザの localStorage に保存された個人データ（購入検討価格・メモ・監視条件）
    と突き合わせて画面に表示
```

### なぜこの構成か（重要な設計判断）

- **個人の投資記録（購入検討価格・投資理由メモ・監視条件）はブラウザの localStorage にのみ
  保存され、サーバーにもGitHubにも一切送信・保存されません。** これにより、リポジトリが
  万が一外部に見える状態になっても、個人の投資判断が漏れることはありません
  （ご本人の希望により採用した方式です）。
- リポジトリは **非公開 (Private)** を前提としています。株価・財務データ自体は公開情報ですが、
  念のため非公開運用とし、公開リポジトリの `stock-screener` プロジェクトとは完全に分離しています。
- localStorage はこの端末・このブラウザにしか保存されないため、**機種変更やブラウザの
  データ消去で消えます。** 定期的に「設定」タブの JSON エクスポートでバックアップしてください。

## 銘柄コードの自動更新への反映について（運用方法）

自動更新（GitHub Actions）は、**どの銘柄コードのデータを取得すべきか**を知る必要があります。
しかし個人データ（購入検討価格・メモ等）と違い、「監視したい銘柄コードのリスト」だけは
GitHub Actions 側にも伝える必要があります（J-Quants APIの呼び出しはブラウザから直接
行えないため＝APIキーをブラウザに置くのは安全ではないため）。

ご要望（最初に登録すれば基本は自動更新、銘柄の追加・変更は数か月に一度程度でよい）に
合わせて、**手動運用**を採用しました:

1. アプリの「登録・管理」タブで銘柄を登録・削除する（購入検討価格・メモ・監視条件も含む）
2. 「設定」タブの「登録銘柄コードをコピー」ボタンを押す（コード一覧がクリップボードに
   コピーされます。コピーできない環境では画面に表示されるテキストを選択してコピー）
3. `data/watchlist_codes.json` に貼り付けて保存し、GitHubにコミット・プッシュする

銘柄構成を変えない限りこの作業は不要で、毎朝の株価・財務データの自動更新はこのファイルの
内容に基づいて完全自動で行われます。数か月に一度、銘柄を増減したときだけこの3ステップを
行ってください。

## セットアップ（ローカル確認）

```bash
cd stock-watch
pip install -r requirements.txt
cp .env.example .env       # JQUANTS_API_KEY を記入（既にお持ちのキーを使用）
```

### サンプルデータで画面を確認する（APIキー不要）

```bash
python scripts/seed_sample_data.py
python -m http.server 8000 --directory site
```

ブラウザで `http://localhost:8000` を開いてください。表示される値はすべてダミーです
（「サンプル」バッジが表示されます）。

### 実データを取得する（JQUANTS_API_KEY 設定後）

```bash
# data/watchlist_codes.json に監視したい銘柄コードを書いてから実行
python -m src.main
```

既存DBのデータだけで画面JSONを再生成したい場合（API呼び出しなし）:

```bash
python -m src.main --skip-fetch
```

## テスト

```bash
pytest tests/ -v
```

財務指標計算・割安成長株スクリーニングロジックの単体テスト（APIに依存しません。
欠損値が0ではなくNone/「取得不可」として伝播することを確認しています）。

## データ取得元

| 項目 | 内容 |
|---|---|
| 提供元 | J-Quants API（JPX総研） https://jpx-jquants.com/ |
| 株価データ | 日次四本値・調整後終値・出来高・時価総額。平日1日1回更新想定 |
| 財務データ | 決算情報（売上高・営業利益・EPS・BPS等）・配当情報。企業の決算発表タイミングに依存 |
| 認証方式 | ダッシュボードで発行したAPIキーをヘッダー `x-api-key` に設定（コードには書かない） |
| 無料枠 | Freeプラン: 5リクエスト/分（銘柄ごとに価格・決算・配当で計3コール必要） |
| 利用規約 | J-Quants利用規約に基づく。契約プランにより取得可能範囲・レート制限が異なる |

取得できなかった項目は `null`（画面上は「取得不可」）として扱い、0や推測値で
埋めることはありません。

## 自動更新（GitHub Actions）— 未設定

`.github/workflows/update.yml` を用意していますが、**まだ有効化していません**
（リポジトリ作成・GitHub Secrets設定・GitHub Pages公開は、ご本人の承認後に行います）。
想定している内容:

- 平日朝7:00 JST（UTC前日22:00）に自動実行、または手動実行（workflow_dispatch）
- `JQUANTS_API_KEY` を GitHub Secrets から読み込む（コードには書かない）
- データ取得 → `data/watchlist.db` 更新 → `site/data/*.json` 再生成 →
  DBとJSONをコミット（過去データは削除しない）→ GitHub Pagesにデプロイ
- 取得に失敗した銘柄があっても、他の銘柄の処理は止めない（エラーは `errors` テーブルに記録）
- 正常な過去データは、取得失敗時も削除しない（DBは upsert のみ、履歴テーブルはない設計だが
  既存の最新値は上書きされるまで残る）

## セキュリティ

- `JQUANTS_API_KEY` はコードに直接書かず、ローカルは `.env`（`.gitignore`済み）、
  GitHub Actionsでは Secrets から読み込みます。
- 購入検討価格・投資理由メモ・監視条件は **ブラウザのlocalStorageにのみ保存** され、
  リポジトリ・サーバーのどこにも送信されません。
- 証券口座の認証情報・実際の売買は一切扱いません。

## 注意事項

本アプリは個人用の株式監視ツールです。将来の株価や業績を保証するものではありません。
掲載情報を利用した投資判断は、利用者ご自身の責任で行ってください。
